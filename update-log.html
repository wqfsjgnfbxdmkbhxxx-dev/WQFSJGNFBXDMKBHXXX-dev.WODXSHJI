v9.4
GPT 生图功能
  • 新增 GPT 生图功能，可在设置中单独开启和配置。
  • 支持填写自己的 API 地址、API Key 和模型名称。
  • 可选择图片尺寸、生成质量、输出格式、背景是否透明、内容过滤强度和附加提示词。
  • 支持直接测试生成，方便确认配置是否可用。
  • 角色现在可以在私聊、群聊、线下互动中发送 GPT 生成的图片。
  • 角色现在可以在动态中发布 GPT 生成的图片。
  • GPT 图片支持在聊天中查看、下载、重新生成、转发，也会正常显示在聊天列表和图片图库里。
  • 手动编辑消息时，新增“谷歌图”和“GPT 图”格式快捷按钮。
图片功能优化
  • 优化图片转发，NovelAI、谷歌生图和 GPT 生图转发后会保留图片和提示词，不再容易只剩下空内容。
  • 优化图片图库和动态中的图片显示，减少特殊文字或链接导致图片显示异常的情况。
  • 优化谷歌生图的模型获取，只显示可实际用于生成图片的模型，减少选到无效模型的情况。
  • 优化谷歌生图请求方式，提高部分配置下获取模型和生成图片的成功率。
  • NovelAI 生图及测试新增超时提醒：等待超过 3 分钟会提示检查网络或稍后再试，避免一直无反应。
  • 优化 NovelAI 图片生成流程，部分场景下角色发送 NovelAI 图片会更稳定。
音乐功能补充优化
  • 优化播放器控制栏，顺序播放、随机播放、单曲循环、上一首、下一首等按钮改为更直观的图标显示。
  • 优化深色模式下的音乐播放器显示，按钮和文字更清晰。
  • 优化播放列表顶部布局，把上传、批量管理、歌单管理、音乐账号、清理失效歌曲等操作收进“更多”菜单，页面更整洁。
  • 新增网络音频批量导入：可一次粘贴多行链接，也支持“歌名、歌手、链接”的格式。
  • 优化本地音乐批量导入：一次选择多首歌时会自动从文件名识别歌名和歌手，不再逐首弹窗询问。
  • 优化单首音乐添加流程，添加完成后提示更简洁。
  • 优化本地歌曲保存：未配置上传服务时会直接保存在本地；上传失败时会自动改为本地保存，减少导入失败。
  • 优化空播放列表时的提示方式，不再弹出突兀的系统提示。
聊天与使用稳定性
  • 优化聊天列表，点击整条聊天记录都可以进入对话，不必只点文字区域。
  • 修复长按聊天或消息后又误触普通点击的问题，长按操作更稳定。
  • 优化部分功能页面的加载处理，页面尚未加载完成时，不容易因为按钮找不到而影响其他功能使用。
  • 优化图片消息的显示处理，减少特殊内容造成图片卡片显示异常的情况。
  • 优化自动相册定时任务的启动位置，情侣空间自动生成相册的功能会更稳定。
